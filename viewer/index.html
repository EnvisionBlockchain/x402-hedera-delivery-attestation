What this page proves, and what it does not. It reads the attestations from the public Hedera mirror node, resolves each attester's DID from its own separate HCS topic, and verifies each signature against the key that DID publishes — not against the key the message carries, which an attacker controls. It also fetches every payment transaction independently and reports what the ledger says settled.

This matters because the attestation topic has no submit key, and having been created without an admin key it can never be given one: anyone may append to it. So an entry appearing here is not evidence of anything by itself. Entries that fail verification are shown and marked, never hidden, but they are excluded from the reputation counts.

Not proven here: that the attester's judgement was correct, only that the attestation is genuinely theirs and unaltered. Signature checking uses vendored @noble cryptography, listed in NOTICE. npm run attestations performs the same verification from the command line. Both check Ed25519, which is what every did:hedera root key is.
